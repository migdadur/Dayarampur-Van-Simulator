# Dayarampur Van Dash 3D

A 3D Bangladeshi van-driving game built with Three.js.

## Play
Deploy to Vercel — no build step needed. It's a single static HTML file.

## Controls
- **W / ⏩** – Accelerate
- **S / 🛑** – Brake (hold at a stop to reverse)
- **A/D or ◀ ▶** – Steer
- **🔔** – Honk (scares cows)
